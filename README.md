# Dermofarmacia · Farmacia Ruiz de Azúa

Maqueta interactiva para explorar una futura reserva de asesoramiento personalizado.

## Probar

Abre `index.html` en un navegador o visita la página publicada con GitHub Pages.
El HTML incluye las fuentes, imágenes, estilos y JavaScript y no necesita compilación.

## Alcance

Calendario y horarios ficticios, datos de prueba, preguntas opcionales, revisión y
confirmación simulada. No se realizan reservas, no se envían formularios y no hay
pagos, analítica ni almacenamiento persistente creado por la página.

El diseño utiliza la identidad visual y los recursos públicos de
[Farmacia Ruiz de Azúa](https://farmaciaruizdeazua.com/). Es una propuesta de prueba,
no una plataforma oficial de reserva operativa. Los recursos de marca y fotografía
pertenecen a sus respectivos titulares.

Antes de ponerla en servicio hay que conectar una agenda real y validar con la
farmacia disponibilidad, modalidad, duración, condiciones y tratamiento de datos.
