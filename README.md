# Dermofarmacia · Farmacia Ruiz de Azúa

Página de información y reserva de asesoramiento personalizado de dermofarmacia.

## Probar

Abre `index.html` en un navegador o visita la página publicada con GitHub Pages.
El HTML incluye las fuentes, imágenes, estilos y JavaScript y no necesita compilación.

## Reservas

La página integra la programación pública «Disponibilidad dermoasesorías» de
Google Calendar. La disponibilidad, el formulario, las confirmaciones y los datos
de la cita son gestionados por Google Calendar. También se ofrece un enlace para
abrir la agenda a pantalla completa.

El diseño utiliza la identidad visual y los recursos públicos de
[Farmacia Ruiz de Azúa](https://farmaciaruizdeazua.com/). Es una propuesta de prueba,
no una plataforma oficial de reserva operativa. Los recursos de marca y fotografía
pertenecen a sus respectivos titulares.

La farmacia es responsable de mantener la agenda, las condiciones del servicio y
la información sobre el tratamiento de datos de las reservas.
